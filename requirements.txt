# XML entity expansion is a memory amplification primitive, and a pasted Wazuh
# ruleset is attacker-reachable. libexpat's amplification limit happens to stop a
# billion-laughs document on this platform, which is an implementation detail of
# one C library rather than a guarantee this tool makes. defusedxml refuses DTDs
# and entity declarations outright, so the property is stated instead of assumed.
#
# There is NO SILENT FALLBACK to xml.etree: a missing defusedxml is a loud
# refusal naming this line, because a fallback would restore the exact accident
# this replaces and would do it invisibly.
defusedxml>=0.7,<1.0

# THE SIGMA CONVERSION PINS ARE GONE, AND THIS IS WHY.
#
# This block used to pin `pysigma` and five backends (splunk, elasticsearch,
# qradar, crowdstrike, azure), with a comment saying they were "left in place
# deliberately, because removing them is a decision about whether Sigma
# conversion comes back, and that is not mine to make."
#
# The decision is now made, on three grounds that are all verified rather than
# asserted:
#
#   1. Sigma is not a target. It is an interchange format with no execution
#      semantics, and its value here is as a TEST CORPUS -- public
#      repositories of rules to test the existing dialects against, not a
#      sixth dialect to implement or a conversion feature to rebuild.
#   2. Nothing imports any of them. `git grep pysigma` finds zero import
#      statements in .py, .js, .html or tests. They install six packages to
#      satisfy nothing.
#   3. Leaving them implies the feature. A dependency list is a claim about
#      what the tool does, and these lines claimed conversion that does not
#      exist -- the same class of false claim as the comments this project
#      keeps deleting.
#
# PyYAML STAYS, and for one reason only: reading that corpus needs a YAML
# parser, and the public Sigma repositories the tool tests against are YAML.
# It is the corpus reader's dependency, not conversion's. If no corpus reader
# is ever built, it goes too.
PyYAML>=6.0.3,<7.0
